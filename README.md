# Botzy WP Sync

## Descripción

Botzy WP Sync conecta un sitio WordPress con [Botzy](https://botzy.app/) para que el bot pueda consultar sus contenidos y responder preguntas mediante búsquedas por tipo de contenido.

Desde el panel de WordPress puedes elegir los tipos de contenido disponibles para Botzy, seleccionar los campos adicionales que compartes y configurar el límite de resultados y los parámetros de búsqueda. El plugin genera una clave de API para conectar el sitio con el bot y permite regenerarla desde sus ajustes.

El acceso a publicaciones privadas se habilita de forma explícita en la configuración del plugin.
